# UI Guidelines

## Theme

Modern clean gaming interface.

---

## Colors

- Dark background
- Bright interactive cards
- High contrast text

---

## Animations

- Smooth card flip animation
- Pop animation when cards disappear
- Smooth hover effects

---

## Layout

- Centered game board
- Responsive grid
- Mobile friendly

---

## UX

- Clear remaining flips display
- Clear win/loss feedback
- Smooth transitions
